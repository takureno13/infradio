# いんふらじお

インフラとITのニュースと、今日の学習テーマを毎朝届ける朝ラジオ。

- 局のページ: https://takureno13.github.io/infradio/
- 配信: 毎朝 06:10 (Asia/Tokyo)
- 内容: インフラ寄りのITニュース + 学習テーマ（仮想基盤・ストレージ・Perforce・英語など）

## 声のクレジット

- 声: Irodori-TTS-v4.1-Anime (phasefield-audio) / 参照音声: つくよみちゃん (COEIROINK)
- 音声合成（声質の参照）には、フリー素材キャラクター「つくよみちゃん」が無料公開している音声データを使用しています。
  - つくよみちゃんコーパス (CV.夢前黎) https://tyc.rei-yumesaki.net/material/corpus/
- 予備音声: COEIROINK:つくよみちゃん

## しくみ

この局は [myradio](https://github.com/monoradio102/myradio) テンプレート（ものラジオ）を基にしています。
原稿は say（読み）と show（表示）を分けて持ち、読み替え辞書で読みを正規化してから音声合成します。
